模糊检测批量处理系统

非技术人员 / 质检操作员使用手册 Windows Docker 版

这是一份给日常操作人员使用的说明书，不需要编程知识。系统会自动检查照片、整理结果，并把需要人工确认的图片集中显示出来。请按照页面顺序操作。

一、开始前请先检查

1. 准备电脑和照片

  • 确认 Windows 电脑已经开机，并且网络和显示器工作正常。
  • 如果照片在移动硬盘、U 盘或移动 SSD 中，请先连接设备，并确认可在“文件资源管理器”中打开。
  • 确认程序文件夹中能看到 blur_detection.bat。
  • Docker Desktop 应由 IT 人员提前安装和设置。若电脑从未运行过本系统，请先联系 IT 人员。
操作员无需安装软件：日常使用只需双击启动文件、选择照片文件夹和操作网页。请勿自行修改程序文件、模型文件或 Docker 设置。

2. 检查图片名称（非常重要）

图片名称必须是 序列号-位置。序列号与位置之间要有一个短横线 -。

例子是否正确原因
1359-3.jpg正确序列号是 1359，位置是 3。
4582A-9.bmp正确序列号是 4582A，位置是 9。
image_3.jpg错误没有使用规定的短横线格式。
1359_pos3.png错误位置前使用了其他文字。

每个产品通常应有位置 1、3、5、7、9 的图片。名称错误或图片缺少时，系统会要求人工复核。

最重要的提醒：程序运行后会出现一个黑色窗口。处理和审查期间，请保持这个窗口开启，也不要在窗口等待画面中随意按键。关闭窗口或按键会停止系统，浏览器页面也会无法使用。

二、启动系统并处理照片

1
双击启动文件
打开程序文件夹，双击 blur_detection.bat。随后会出现一个黑色窗口。
2
等待系统准备完成
如果 Docker Desktop 尚未运行，系统会自动打开它。一般需要等待 20–45 秒。请不要关闭任何窗口。
3
告诉系统照片放在哪里
黑色窗口出现 Is your data drive external or internal? 时：
照片在移动硬盘、U 盘或移动 SSD，按键盘 E；照片在电脑本机磁盘，按键盘 I。
4
选择照片文件夹
文件夹选择窗口出现后，单击存放待检测照片的文件夹，再点击“确定”。不要只选择一张图片，要选择包含图片的整个文件夹。

处理结果会保存在哪里？

照片位置照片文件夹示例结果文件夹
外接盘（E）E:\项目A\照片E:\pipeline_outputs\项目A\照片
内置盘（I）D:\项目A\照片D:\项目A\照片\pipeline_outputs

系统会自动建立结果文件夹，无需操作员手动创建。

5
等待网页打开
浏览器会自动打开操作页面。若没有自动打开，请打开 Chrome 或 Edge，在地址栏输入 http://localhost:8501，然后按 Enter。
6
开始处理
网页右上角选择 ZH 切换为中文。在“批量处理”页确认：输入框显示 /data/input，输出框显示 /data/output，设备显示 cuda。然后点击“运行批量流清洗处理”。
怎样知道已经完成？网页会显示“批处理执行完毕”，并列出处理数量、需要复核的数量和处理时间。处理完成前，请勿拔出数据盘、关闭浏览器或关闭黑色窗口。
不要修改两个路径框：/data/input 和 /data/output 是系统自动使用的地址，并不是 Windows 文件夹名称。日常操作时保持原样即可。

三、图像人工审查与标注

批处理完成后，点击网页顶部的“人工审查与标注”。页面中的预测结果和图片位置通常会自动填好，操作员不需要修改。

按照以下顺序审查
  • 选择要看的记录：可使用状态筛选，只查看“待人工审查”“FLC”或“NG”等记录。不确定时保持全部选中。
  • 放大图片：把鼠标停在图片上即可放大，移开鼠标即可恢复。
  • 检查每个位置：如果系统判断错误，点击图片左侧的 OK、太远、稍近、太近或 NG。
  • 确认整个产品：可点击“需要 FLC 异常复核”“正常无需 FLC”或“报废（直接NG）”。
  • 保存并继续：点击“下一页”保存当前产品并进入下一条。也可以按键盘 →。需要回看时点击“上一页”或按 ←。

1. 五个判断按钮是什么意思？

按钮意思什么时候使用
OK正常目标位置正常，没有明显偏移或距离问题。
太远距离太远目标明显太远、严重偏移，或目标区域不完整。
稍近轻微偏近目标有一点偏近，但边界仍可看清。
太近距离太近目标明显过近、严重模糊、被放大，或重要区域看不到。
NG异常或报废图片缺失、系统处理错误，或有无法接受的严重问题。

2. 什么时候会自动要求 FLC 复核？

FLC 表示“需要进一步异常复核”。位置 1、3、5、7、9 中，出现以下任一情况时，系统会自动要求 FLC：

  • 至少 1 个位置是太近；
  • 至少 1 个位置是 NG；
  • 有 3 个或更多位置是稍近。
操作提示：顶部三个按钮可以直接决定整个产品的状态。如果之后又修改某个位置，系统会重新计算。请在检查完五个位置后，再确认整个产品的最终状态。

四、查看结果与结束工作

1. 操作员应该查看哪些文件？

打开前面说明的结果文件夹，再进入 dataset_output 文件夹。日常查看请优先打开 Excel 文件（文件名以 .xlsx 结尾）。

文件用途
consolidated_batch_predictions.xlsx全部产品的系统检测结果。
predictions_filtered.xlsx只包含需要人工检查或 FLC 复核的产品。
human_annotated_predictions.xlsx人工审查并保存后的最终结果。质检工作完成后应主要查看此文件。
raw_predictions.xlsx每张原始图片的详细检测数据，一般仅在排查问题时使用。
不要修改系统文件：同一文件夹中的 .json 文件供系统读取。操作员可以查看 Excel，但不要删除、改名或手动编辑 JSON 文件。processed_images 文件夹保存处理后的图片。

2. 正确结束工作

  1. 确认网页显示处理已经完成，并且人工审查已保存。
  2. 回到黑色窗口，按键盘任意键。
  3. 等待系统自动停止。当窗口提示可以安全关闭时，再关闭窗口。
  4. 如果使用移动硬盘，请完成以上步骤后再安全弹出硬盘。

3. 遇到问题怎么办？

看到的情况操作员可以这样做
等待很久，仍未打开网页确认黑色窗口没有关闭。手动打开 Docker Desktop，等待它完成启动，再重新双击启动文件。
浏览器没有自动打开保持黑色窗口开启，在 Chrome 或 Edge 输入 http://localhost:8501。
网页显示设备为 cpu先停止程序，然后联系 IT 人员。正常运行应显示 cuda。
系统找不到照片文件夹检查移动硬盘是否连接，再重新启动并选择文件夹。
很多产品显示图片缺失检查文件名格式，并确认每个序列号是否有位置 1、3、5、7、9。
网页突然无法使用检查黑色窗口是否被关闭。若已关闭，请重新双击启动文件；不要同时启动两次。
仍然无法解决？请不要修改程序。拍下黑色窗口和网页错误信息的照片，并把照片、所选文件夹位置和发生时间一起发给 IT 人员。
